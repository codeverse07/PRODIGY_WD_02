# PRODIGY_WD_02
A stopwatch web application designed in Html , Css and javascript having all the functions as in a stopwatch .
Technologies used :
* Html for designing the body and front user page of the stopwatch which gives it a good feel design and interface .

*CSS for the muscle part which gives it a stunning look and also make it user attractive to be used. While hovering through its buttons one can see a change in its colour which show its highlights.

*Javascript as the final part of the code which gives a soul in the code and makes its functionable for the user . 

Also besides this i have attached multiple buttons for good user experience and a friendly user interface .
